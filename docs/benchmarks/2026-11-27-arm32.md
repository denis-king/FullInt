# ARMv7 (32-bit Linux): FullInt against GMP and BigInteger

2026-11-27. Oracle Ampere A1 (Neoverse-N1) running AArch32 code natively: an `ubuntu:24.04` armhf container (`--platform linux/arm/v7`), pinned to one core (`--cpuset-cpus=1`). C++: GCC 13, `-O3`, against GMP 6.3 (Ubuntu's armhf package, `fullint_bench_api`). .NET: .NET 10.0.15 (linux-arm), `FullInt.Benchmarks cross`, both libraries warmed up per operation and size. A word is 64 bits; the operands are random, `div` / `mod` a 2N-word dividend by an N-word divisor.

Every kernel the engines use is in assembly (`FullInt.Asm/Sources/arm32`, see [PLATFORMS.md](../PLATFORMS.md#armv7-32-bit-linux-armhf)). Raw times: [the C++ CSV](2026-11-27-arm32-cpp-vs-gmp.csv), [the .NET CSV](2026-11-27-arm32-net10.csv).

Multiplication from 1024 words runs on the NTT (NEON: `arm32/NttNeon.s`), the divisions and the decimal conversions of long numbers on it through Newton's reciprocal. From 16 words the shifts take 1.1-1.5x GMP's time and `and` 1.2-2.4x (its loops are wider); against `BigInteger` they are ahead there (below).
