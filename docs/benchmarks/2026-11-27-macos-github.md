# FullInt on macOS (GitHub Actions)

2026-11-27, `.github/workflows/bench-macos.yml` on GitHub's hosted machines: **macos-15** (Apple M1,
virtual, 3 cores) and **macos-15-intel** (Intel Core i7-8700B, 4 cores). These are shared virtual
machines: read the numbers as indicative - single cells are off by 10-30% and a few by far more
(C++ `add` / `todec` of one word at 0.01-0.02 and `div` of 4 words at 0.04 are measurement
artifacts, not speed). The other platforms' numbers come from dedicated machines:
[2026-11-27-all-platforms.md](2026-11-27-all-platforms.md).

The .NET package has no macOS library yet: on both Macs .NET runs the **managed core**. The C++
library on Apple Silicon runs the AArch64 assembly kernels (Mach-O). Raw times:
[2026-11-27-macos-arm64-cpp-vs-gmp.csv](2026-11-27-macos-arm64-cpp-vs-gmp.csv), [2026-11-27-macos-arm64-net10.csv](2026-11-27-macos-arm64-net10.csv),
[2026-11-27-macos-x64-net10.csv](2026-11-27-macos-x64-net10.csv).

On the Intel Mac add / sub on the managed core are slower than `BigInteger` (0.63-0.98); the x64
assembly kernels (the Linux library's, built as Mach-O) would take them to Linux x64's 1.1-4x - the
macOS native library is the next platform step.
